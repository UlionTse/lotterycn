    策略为纯注入设计：needs_history / method / aliases 三个类属性声明，由基类 __init_subclass__ 自动注册；load_predict_numbers 工厂统一解析并注入历史数据。

    仅供娱乐，不构成任何预测力

    predict ¶

    选号策略集（娱乐与教学用途）。

    仅供娱乐，不构成任何预测力

    彩票开奖为独立随机事件，以下任何策略都不具备真实预测力，任何一注号码的 中奖概率与随机选号完全相同。本模块仅提供统计选号参考与教学示例； random 为基线策略，任何策略都应先与它对比（可用 lotterycn.backtest 复现实验）。请理性购彩。

    策略来源（社区彩票圈/股票分析框架的平移，均无真实预测力）： 随机基线 random 走势图派 frequency（冷热）、omission（遗漏回补）、tail（尾数）、trend（和值均线通道） 形态派 filter（奇偶/大小/质合/012路/三区比/AC值/连号/杀号 可组合缩水） 序列派 markov（一阶）、markov2（二阶，稀疏性教学）、repeat（重号/邻号/斜连号） 统计派 deviation（卡方偏离度） 集成派 ensemble（多策略投票）

    设计约定：策略类是"纯注入"的——构造器不做任何网络 IO，历史数据由 load_predict_numbers 工厂统一解析并注入（子类通过 needs_history 声明是否依赖历史，通过 aliases 声明别名，两者均由基类自动注册）。 需要历史数据的子类调用 self._require_history()。

    BasePredictor ¶

    BasePredictor(
    lottery_name: str = "ssq",
    history: Optional[DataFrame] = None,
)

    策略基类（纯注入，构造器零 IO，torch Layer 风格）。

    子类声明三个类属性，注册由基类 __init_subclass__ 自动完成： needs_history — 是否依赖历史数据（工厂据此决定是否联网拉取并注入）； method — 输出 DataFrame 的 method 列标签，同时作为注册键； aliases — 别名 → 策略参数覆盖（可选）。

    Bases: BasePredictor

    遗漏回补策略（均值回归）：按"当前遗漏 / 平均遗漏"的偏移度取号。

    直觉：某号码当前连续未出期数远超其历史平均遗漏时，社区称之为"遗漏 回补"。数学真相：独立开奖下这仍是均匀抽样的另一种表达，不改变概率。

    注意：过滤只改变选号的分布形态，不改变任何一注的中奖概率。

    EnsemblePredictor ¶

    EnsemblePredictor(

    history: Optional[DataFrame] = None,
    members: tuple = ("frequency", "omission", "repeat"),

    Bases: BasePredictor

    集成投票策略：多个子策略各出 top-k，按号码得票数取前 k。

    集成不改变期望——各子策略无预测力，投票亦然；提供它是为了 把"多策略共振"这一社区习惯变成可复现的实验。

    		 ('frequency', 'omission', 'repeat')
    votes_min int

    int, 入选号码的最少得票数；不足 k 个时按票数补齐。

    		 1

    load_predict_numbers ¶

    load_predict_numbers(
    lottery_name: str = "ssq",
    method: str = "random",
    amount: int = 1,
    history: Optional[DataFrame] = None,
    **kwargs,
) -> DataFrame

    Generate numbers with a strategy. Output mirrors load_random_data (plus a method column).

    ⚠️ Entertainment only — every strategy has exactly the same expected value as the random baseline (verify with lotterycn.backtest).

    中文说明

    按指定策略生成选号。可用策略：random 基线 / frequency 冷热（别名 hot/cold）/ omission 遗漏回补（chase）/ deviation 卡方偏离（chisq）/ repeat 重邻斜 / trend 和值均线 / tail 尾数 / markov / markov2 / filter 形态缩水（和值/奇偶/质合/三区/012路/AC值/连号/杀号）/ ensemble 多策略投票。history= 注入 DataFrame 可完全离线； 否则按需拉取（支持 if_cached）。

    Parameters:

    Name Type Description Default
    lottery_name str

    str, must in ('ssq', 'qlc', 'kl8', '3d', 'dlt', 'pls', 'plw', 'qxc').

    		 'ssq'
    method str

    str, 'random' | 'frequency'（别名 'hot'/'cold'）| 'omission'（'chase'） | 'deviation'（'chisq'）| 'repeat' | 'trend' | 'tail' | 'markov' | 'markov2' | 'filter' | 'ensemble'.

    		 'random'
    amount int

    int, 生成注数，default 1.

    		 1
    history Optional[DataFrame]

    pandas.DataFrame, 显式注入历史数据（离线使用）；为 None 且策略 需要历史时按 **kwargs 中的数据获取参数联网拉取。

    		 None
    **kwargs

    两类参数—— 策略参数：recent_n / mode / explore_ratio（frequency/omission/deviation/tail）， repeat_weight / neighbor_weight / jump_weight（repeat）， window / k_sigma（trend），members / votes_min（ensemble）， sum_range / odd_range / prime_range / zone_ratio / mod3_range / ac_range / consecutive_range / exclude_numbers / max_trials（filter）； 数据获取参数（仅拉取时生效）：if_cached / timeout / proxies / max_retries 等。

    		 {}
