    odds — 中奖概率与奖金期望¶

    基于官方规则的精确组合数学：各奖级中奖组合数、概率、单注期望奖金与返奖率；含大乐透追加/复式口径。

    odds ¶

    LotteryPac ¶

    LotteryPac(cfg)

    中奖概率与奖金期望计算框架。

    各彩种的奖级、中奖条件与奖金均以官方游戏规则为准（详见 config.py 中的规则来源）， 浮动奖按默认假设值计算期望，可用环境变量覆盖（键名见各配置类的 *_prize_env）。

    load_dlt_compound_expectation ¶

    load_dlt_compound_expectation(n_red: int = 5, m_blue: int = 2, if_pool_over_800m: bool = False, if_add_bet: bool = False) -> DataFrame

    返回大乐透复式投注的注数、成本与整票期望。

    复式票选定 \(n_{red}\) 个前区号码与 \(m_{blue}\) 个后区号码，组合为 \(\binom{n_{red}}{5}\times\binom{m_{blue}}{2}\) 注单式。开奖后前区命中 \(r\) 个、后区命中 \(b\) 个时：

    \[P(r,b)=\frac{\binom{5}{r}\binom{30}{n_{red}-r}}{\binom{35}{n_{red}}} \times\frac{\binom{2}{b}\binom{10}{m_{blue}-b}}{\binom{12}{m_{blue}}}\]
    \[\text{i 等奖中奖注数}=\sum_{(j,l)\in R_i}\binom{r}{j}\binom{n_{red}-r}{5-j} \binom{b}{l}\binom{m_{blue}-b}{2-l}\]
    \[\mathbb{E}[\text{整票奖金}]=\sum_{r,b}P(r,b)\cdot\text{Prize}(r,b)\]

    由期望的线性性，整票期望恒等于 总注数 × 单式期望（返奖率不变）， 复式只改变成本与方差。

    Name Type Description Default
    n_red int

    int, 前区号码个数，5-35。

    		 5
    m_blue int

    int, 后区号码个数，2-12。

    		 False
