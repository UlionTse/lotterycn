    load_history_data ¶
    load_history_data(lottery_name: str, **kwargs) -> Union[list, DataFrame]

    Load draw history for all 8 games as a tidy DataFrame.

    Fetches from the official websites (cwl.gov.cn / lottery.gov.cn) with retry/backoff; supports incremental CSV caching.

    中文说明

    拉取 8 个彩种（大乐透/排列3/排列5/7星彩/双色球/七乐彩/快乐8/福彩3D） 的历史开奖数据，输出统一列结构的 DataFrame （lottery_name / lottery_order / lottery_date / lottery_red / lottery_blue）。

    • if_cached=True 启用本地 CSV 缓存与增量更新（目录默认 ~/.lotterycn/history，可用 cache_dir 或环境变量 lotterycn_cache_dir 覆盖）；
    • 福彩系支持 begin_date 日期区间增量，体彩系全量刷新后去重。

    Parameters:

    Name Type Description Default
    lottery_name str

    str, must in ('dlt', 'pls', 'plw', 'qxc', 'ssq', 'qlc', 'kl8', '3d').

    		 required
    **kwargs

    :param is_detail_result: boolean, default False. :param if_cached: boolean, default False. Enable local CSV cache + incremental update. :param cache_dir: str, default None (~/.lotterycn/history). :param begin_date: str, welfare games only. :param timeout: float, default 15. :param max_retries: int, default 3. :param proxies: dict, default None. :param sleep_seconds: float, default random.random().

    		 {}

    Returns:

    Type Description
    Union[list, DataFrame]

    list or pandas.DataFrame
